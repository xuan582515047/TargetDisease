# TargetDisease visual system

The user's current request for bright biotechnology aesthetics supersedes the earlier dark direction.

## Direction

Bright laboratory surfaces: white panels, mist-blue backgrounds, pale mint biological-network illustrations, deep blue-gray text and restrained teal actions. Retain the layouts in pages/studio.md and all functional flows.

UI UX Pro Max's `biotech healthcare light --design-system` returned a healthcare palette, but its testimonial pattern and neumorphism were inappropriate and rejected. The narrower `healthcare --domain color` verified the cyan/health-green direction. Use clear borders rather than embossed controls.

## Tokens

- Background #f4f9fb; white cards; border #d5e4e8.
- Text #173d50; secondary #526d7e.
- Action #087f8c with white text; hover #066875.
- Biological accents: mint #e5f5ee and blue #e4f1fb.
- Green success, amber pending and red errors always accompanied by labels.
- Existing local sans fonts; no remote font dependency.
- Bright authentication and sidebar; native controls use light color scheme.

## Interaction and integrity

- Homepage network is explicitly a process illustration, never represented as a real analysis.
- Three tabs are click- and keyboard-operable, with semantic selected state and a corresponding panel.
- No invented accuracy, evidence counts, live system status, or scientific claims.
- Respect reduced motion. Visible focus indicators; native labels and disabled states.
- Real analysis remains tied to the existing authenticated API and the user's model credential.

## Validation sizes

375, 768, 1024 and 1440 CSS pixels. Verify no horizontal overflow, readable labels, preserved form actions, and full feature access.
